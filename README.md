Time speeds up smoothly while you work — and returns to normal when you stop.
In multiplayer, time accelerates when everyone is busy, with shared Pause and manual Wait controls.

Safety first
Time will never accelerate when immediate danger is present — such as nearby zombies, fires, bleeding wounds, or noxious smell.

Singleplayer
The vanilla time controls remain unchanged.
Automatic acceleration kicks in when time is at normal speed and your character is busy.
Speed ramps up progressively towards the maximum speed, then returns to normal immediately when the action ends.
Momentum builds up and is maintained even while rapidly chaining short tasks.

Multiplayer
Three buttons replace the usual solo controls: Pause, Normal, and Wait.
Normal: Time accelerates automatically when all players are busy.
Pause: Request a shared pause. The button pulses when requested, and the server pauses once everyone clicks it.
Wait: Let time pass even while idle (perfect for watching an oven or waiting for a friend to unload their ).
When a player commits to a long task, the Wait button pulses slowly on everyone else's screen, signaling it's the perfect time to start a long task too.

Visual Feedback
A dynamic row of chevrons grows as time speeds up, letting you see the current acceleration multiplier at a glance.
